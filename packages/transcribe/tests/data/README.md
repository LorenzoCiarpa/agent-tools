# Test data

`jfk.ogg`: the first 11 seconds of John F. Kennedy's 1961 inaugural address
("...ask not what your country can do for you..."). It is a US federal
government work and therefore in the public domain. It was taken from
`samples/jfk.wav` in [whisper.cpp](https://github.com/ggml-org/whisper.cpp) and
re-encoded to mono 16 kHz Opus at 24 kbit/s to keep the repository small.
